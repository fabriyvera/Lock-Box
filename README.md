# LockBox

Plataforma de comercio social seguro. La rama `backend-sellers` conecta el módulo vendedor de Next.js con Express, Supabase Auth y PostgreSQL, conservando la interfaz inicial.

Consulta [BACKEND_SELLERS.md](docs/BACKEND_SELLERS.md) para los datos de prueba, cambios de base, seguridad, configuración y validación. Los fixtures ya están aplicados en LockBox's Project. Lives y operaciones financieras son de prueba; no procesan dinero real.
